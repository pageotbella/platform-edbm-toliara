# CAHIER DES CHARGES

## Projet : Plateforme web interactive de valorisation des opportunités d’investissement à Madagascar au sein de l’EDBM Toliara

---

## 1. Présentation générale du projet

### 1.1. Contexte

L’Economic Development Board of Madagascar (EDBM) est un organisme impliqué dans la promotion des investissements à Madagascar et dans l’accompagnement des investisseurs.

Dans le cadre de ses activités, l’EDBM dispose d’informations relatives aux opportunités d’investissement dans différents secteurs économiques tels que :

* l’énergie ;
* l’agriculture et l’agrobusiness ;
* l’aquaculture ;
* les mines ;
* le tourisme ;
* les technologies de l’information et de la communication ;
* l’industrie ;
* ainsi que d’autres secteurs présentant un potentiel d’investissement.

Ces informations peuvent notamment être présentées sous différentes formes : documents PDF, brochures, fiches de projets ou informations communiquées par les services et représentations régionales.

Cependant, lorsque les opportunités sont dispersées dans différents supports, leur consultation, leur recherche, leur mise à jour et leur valorisation peuvent devenir moins pratiques pour les investisseurs.

Le présent projet consiste donc à mettre en place une plateforme web permettant de **centraliser, structurer, présenter et valoriser les opportunités d’investissement disponibles à Madagascar**, tout en offrant à l’EDBM Toliara un espace d’administration permettant de gérer ces informations.

---

# 2. Problématique

Les informations relatives aux opportunités d’investissement peuvent être difficiles à exploiter lorsqu’elles sont réparties entre plusieurs documents ou supports.

Un investisseur souhaitant identifier une opportunité peut avoir besoin de rechercher :

* un secteur particulier ;
* une région ;
* une zone géographique ;
* un type de projet ;
* un niveau d’investissement ;
* des informations économiques ;
* des documents complémentaires ;
* ou les coordonnées du service à contacter.

L'absence d'une plateforme centralisée et interactive peut donc rendre la recherche moins rapide et limiter la visibilité des opportunités.

La problématique principale du projet est ainsi formulée comme suit :

**Comment mettre en place une plateforme web interactive permettant de centraliser, structurer et valoriser les opportunités d’investissement à Madagascar, tout en facilitant leur recherche par les investisseurs et leur gestion par l’EDBM Toliara ?**

# 4. Objectifs du projet

## 4.1. Objectif général

L’objectif général est de développer une plateforme web permettant de **centraliser, structurer, rechercher, consulter et valoriser les opportunités d’investissement à Madagascar**, tout en facilitant leur gestion par les responsables de l’EDBM Toliara.

---

## 4.2. Objectifs spécifiques

Le projet vise notamment à :

1. Centraliser les informations relatives aux opportunités d’investissement.
2. Structurer les opportunités par secteur et par région.
3. Permettre aux visiteurs de rechercher facilement une opportunité.
4. Mettre à disposition des filtres de recherche avancés.
5. Présenter les opportunités sur une carte interactive de Madagascar.
6. Fournir une fiche détaillée pour chaque opportunité.
7. Permettre aux investisseurs de créer un compte.
8. Permettre aux investisseurs d’enregistrer des opportunités favorites.
9. Permettre à un investisseur de manifester son intérêt pour une opportunité.
10. Permettre aux agents de l’EDBM de gérer les opportunités.
11. Permettre l’ajout et la gestion de documents et de supports multimédias.
12. Mettre en place différents niveaux d’accès selon les utilisateurs.
13. Permettre le suivi des demandes d’intérêt des investisseurs.
14. Fournir des statistiques sur les opportunités et les interactions.
15. Améliorer la visibilité des potentialités d’investissement régionales.

# 32. API REST prévisionnelle

Exemples d’endpoints :

### Authentification

```text
POST /api/auth/sign-up/email
POST /api/auth/sign-in/email
POST /api/auth/sign-out
GET  /api/auth/get-session
```

Ces routes sont fournies par Better Auth. La session est portée par un cookie sécurisé renouvelé automatiquement : il n’existe donc pas de route `refresh`.

### Opportunités

```text
GET    /api/opportunities
GET    /api/opportunities/:id
POST   /api/opportunities
PUT    /api/opportunities/:id
DELETE /api/opportunities/:id
```

### Secteurs

```text
GET    /api/sectors
POST   /api/sectors
PUT    /api/sectors/:id
DELETE /api/sectors/:id
```

### Régions

```text
GET /api/regions
GET /api/regions/:id/opportunities
```

### Favoris

```text
GET    /api/favorites
POST   /api/favorites
DELETE /api/favorites/:id
```

# 47. Conclusion

Le présent projet vise à transformer la manière dont les opportunités d’investissement sont présentées et exploitées au sein de l’EDBM Toliara.

Il ne s’agit donc pas uniquement de développer un simple site web vitrine. La plateforme constitue un **système d’information dédié à la centralisation, la structuration, la valorisation et au suivi des opportunités d’investissement**.

Elle permettra de répondre à deux besoins complémentaires :

### Pour les investisseurs

* trouver plus facilement les opportunités ;
* rechercher par secteur et région ;
* visualiser les projets sur une carte ;
* consulter des informations détaillées ;
* sauvegarder des projets ;
* manifester leur intérêt ;
* suivre leurs demandes.

### Pour l’EDBM

* centraliser les données ;
* structurer le catalogue d’opportunités ;
* mettre à jour les informations ;
* gérer les documents ;
* suivre les investisseurs intéressés ;
* analyser les consultations et demandes ;
* améliorer la promotion des potentialités d’investissement de Madagascar.

Le projet pourra ainsi constituer une base évolutive pouvant ultérieurement être intégrée à d’autres systèmes numériques de l’EDBM.
